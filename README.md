# 📚 MyBook App (Flutter)

A clean and responsive book browsing mobile application built with Flutter, focused on performance, simplicity, and user experience.

---

## 🚀 Overview

MyBook is a mobile application that allows users to explore and browse books through a modern and intuitive interface.

The project focuses on building a smooth and responsive UI while integrating external APIs to fetch and display real-time data.

---

## 📱 Features

* 📖 Browse books with clean UI
* 🔍 Search functionality *(لو موجودة فقط)*
* 📄 Book details screen
* 🌐 API integration for dynamic content
* ⚡ Fast and responsive performance
* 📱 Adaptive layout for different screen sizes
